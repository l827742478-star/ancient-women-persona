# 你最像哪位古代女性人物？

一个可直接运行的中文 H5 趣味测试产品。

## 已包含

- 18 道原创历史意象情境题
- 8 位古代女性人物原型：武则天、花木兰、李清照、班昭、上官婉儿、王昭君、蔡文姬、谢道韫
- 结果类型、人物判词、六项维度条、结果卡下载、结果文案复制
- 本地答题进度保存，刷新后可继续
- 响应式移动端布局与键盘焦点样式

## 本地运行

在当前目录执行：

```bash
python3 -m http.server 45124
```

然后打开 `http://127.0.0.1:45124/`。

## 说明

本产品是娱乐性人物原型映射，不构成历史评价、心理测评、职业诊断或重大决策建议。所有题目、人物命名、判词和视觉文案均为本产品原创。
